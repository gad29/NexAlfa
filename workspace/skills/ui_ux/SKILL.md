# ui_ux

## Description
System skill that enforces premium UI/UX design aesthetics, micro-animations, and dynamic interactions for front-end tasks.

## When to Use
Use this whenever creating or modifying front-end code (HTML, CSS, Next.js, React, Vite) or designing user interfaces.

## Steps
1. ALWAYS prioritize visual excellence. Use curated HSL color palettes or sleek dark modes. Avoid basic raw colors.
2. Ensure micro-animations (hover states, smooth transitions) are applied to all interactive elements.
3. Use modern typography (Inter, Roboto) instead of system default fonts.
4. If building a new web application or layout, consider using tools like `generate_image` to prototype and get visual feedback.
5. Provide the user with a dynamic, living interface that feels responsive and high-end. Do NOT build simple Minimum Viable Products.

## Notes
Aesthetics are critical to NexAlfa's outputs. Failure to produce a stunning, premium design is considered a failure of the task. Always apply Tailwind or Vanilla CSS best practices for glassmorphism and modern UI trends.
